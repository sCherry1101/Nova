# Contributing to N☄VA

Thanks for stopping by. Nova is an experimental web desktop — part chatbot, part playground, part chaos in order.  
If you want to contribute, improve, or just explore, you’re welcome here.

---

## Ground Rules

1. Keep the code readable.  
2. No unnecessary libraries unless they actually improve performance or UX.  
3. Keep the aesthetic consistent — minimal, functional, slightly retro.  
4. If you add a new feature, describe it clearly in the pull request.  
5. Don’t break existing features. If you do, fix them before pushing.

---
